# 👑 Ohemaa’s Apparel - E-Commerce Boutique & Owner Admin Portal

A real-world ready, mobile-first luxury e-commerce web application created for **Ohemaa’s Apparel** featuring 33 high-resolution boutique items and a studio video showcase reel from the `pics` collection.

---

## 📱 Mobile-First Design & Experience
Built specifically for smartphones as the primary browsing device:
- **Instagram/TikTok-Style Story Highlights:** Tap to watch the live studio video reel, explore Friday drops, crown edition shorts, palazzo pants, and wholesale tiers.
- **Fixed Mobile Bottom Navigation Dock:** Instant one-thumb access to Home, Catalog, Studio Reel, Shopping Bag (with live counter badge), and the Owner Admin Portal.
- **Touch-Friendly Product Grid:** 2-column mobile layout with quick-view modal, size & color swatches, and instant add-to-bag gestures.
- **Studio Video Reel:** Real MP4 video (`VID-20261022-WA0108.mp4`) integrated directly with in-line banner preview and full-screen vertical TikTok/Reels player.

## 🚀 Running the Project

### 1. Development Server (Vite)
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your mobile browser or browser mobile device simulator (e.g., iPhone 14/15/Pro, Samsung Galaxy).

### 2. Direct Static File
You can also open `index.html` directly in any web browser, or deploy the folder to **Vercel**, **Netlify**, **GitHub Pages**, or standard cPanel hosting with zero build step required.
